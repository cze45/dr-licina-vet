# Dr Ličina Vet

Sajt veterinarske ambulante Dr Ličina Vet, Beogradski kej 19b, Novi Sad.

## Sadržaj

- `index.html` - ceo sajt u jednom fajlu (Početna, Slučajevi, Kontakt). Radi i bez servera.
- `assets/` - logo ambulante.

## Objava na GitHub Pages

1. Napravite novi repozitorijum i uploadujte sadržaj ovog foldera.
2. U repozitorijumu otvorite Settings > Pages.
3. Pod "Source" izaberite granu `main` i folder `/ (root)`, pa sačuvajte.
4. Sajt će biti na adresi `https://<korisnik>.github.io/<repozitorijum>/`.

## Pre objave

- Radno vreme na sajtu nije potvrđeno.
- Sive površine su mesta za fotografije.
- Forma za upit trenutno ne šalje podatke nigde. Potrebno je povezati je sa servisom za forme (npr. Formspree) ili e-mailom.
